# React Development

Implement frontend changes using the repository's established React stack and visual conventions.

- Inspect the package manager, framework, routing, styling, state management, and component patterns before adding dependencies or abstractions.
- Keep components focused, compose shared behavior deliberately, and colocate state at the narrowest practical ownership level.
- Model loading, empty, error, success, and permission states for asynchronous flows.
- Keep API contracts typed when the stack supports it and handle cancellation, retries, and stale responses where relevant.
- Preserve keyboard access, semantic markup, readable contrast, responsive behavior, and useful form feedback.
- Avoid introducing a parallel design system or generic abstraction for a single use case.
- Add proportionate tests for user-visible behavior and update documentation when contracts or setup change.
- Run the repository's formatting, type-checking, build, and test commands before completion when available.
