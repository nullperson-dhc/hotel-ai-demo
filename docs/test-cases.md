# 酒店预订与入住系统测试用例

## 1. 测试范围与策略

依据 `docs/requirements.md` 与 `docs/api-design.md`，测试覆盖 FR-01 至 FR-06、核心业务规则、事务原子性、并发库存、认证授权、隐私与错误契约。自动化测试以 Spring Boot 集成测试为主，前端执行 TypeScript 编译及生产构建；浏览器人工验收聚焦主流程与反馈状态。

| TC-022 | 重复办理入住 | 订单已 CHECKED_IN | 409 `ORDER_STATUS_CONFLICT`；状态和库存不变 | 是 |

## 3. 认证、安全与接口契约用例

| ID | 场景 | 预期结果 | 自动化 |

## 5. 通过准则

- 十个指定核心场景全部具备可执行测试或明确的人工/API 测试步骤。
- 自动化测试无失败，库存不出现负数，失败事务不留下订单或部分扣减。
- 阻断级或严重级缺陷必须修复后方可通过测试阶段。
